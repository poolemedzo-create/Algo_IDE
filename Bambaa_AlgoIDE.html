  Syntaxe SIMAC prise en charge
  
Algorithme Nom, Variable, Constante, déclarations x : Entier;, constantes comme PI : Réel = 3.14;, Début, Fin., affectation x ← expression; (ou x := expression;), Lire(x), Écrire(...), Si ... Alors, Sinon, FinSi.

  
Types : Entier, Réel, Texte, Booléen. Opérateurs : + - * / ^ % (% = modulo), comparaisons = <> < > <= >=, logique ET OU NON. Boucles Pour, TantQue, Répéter/Jusqu'à, SelonQue, tableaux 1D non pleins et tableaux multidimensionnels (ex. T[i], M[i,j]). Pour un tableau contigu, gérer le nombre de cases utiles avec Taille; pour un tableau à trous, utiliser une valeur sentinelle Trou. Fonctions : Racine(x), Abs(x), Entier(x) (partie entière), Longueur(chaine). Commentaires : // sur une ligne et /* ... */ sur plusieurs lignes. Les instructions exigent ;, et le programme se termine par Fin..
